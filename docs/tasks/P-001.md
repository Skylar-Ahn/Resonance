## 2. 범위

포함: 중립 App Home, For You 데모 목록, 동일 공연의 Overview와 Seat, 좌석도·추천안 동기화, 선택적 기준 조정, 모의 실패·빈 결과·일부 데이터·미지원 상태 및 복귀 경로, 모바일·태블릿·데스크톱·키보드 확인.

제외: 실제 인증·온보딩 화면, 영구 사용자 저장, 추천 랭커/LLM/API/크롤링, 실제 홀의 지원 확정, 예매 연동, Articles·Reviews·Bookmarks CRUD, 실제 음악 재생, 설치 유도·오프라인 캐시·업데이트·알림 구현. 관련 메뉴가 보이는 경우 비활성 상태와 접근 가능한 이름으로 범위 밖임을 구분하고 성공 동작을 가장하지 않는다. 이 프로토타입의 제한은 전체 IA의 기능 삭제가 아니다.

## 3. 정확한 실행 경로

아래 주소는 구현된 로컬 프로토타입 경로다. 실행 명령과 검증 기록은 7절을 따른다.

1. 데모 시작 주소 `/demo`로 진입한다. `demo-user-001`, `onboardingCompleted=true`, Content Preference `실내악`, Experience Preference `연주자의 움직임을 가까이 보고 싶다`를 가진 fixture를 메모리에 초기화한다. App Home에서 1차 메뉴는 모두 비선택이다.
2. `For You`를 선택한다. `/demo/for-you`에서 데모 공연 목록과 좌석·이유 요약을 확인한다.
3. `데모 실내악 공연` 카드(`concert-demo-001`)를 선택한다. `/demo/concerts/concert-demo-001`에서 Overview가 열리고 공연 ID·일시·홀·출연자·프로그램 요약을 확인한다.
4. `Seat` 탭 또는 Overview의 좌석 요약을 선택한다. `/demo/concerts/concert-demo-001/seat`에서 추가 질문 없이 기본 복수 추천을 표시한다.
5. 기본 추천 `연주 관찰`(1층 A구역 3열 5번)을 선택해 좌석 번호·강조 위치·이유를 확인한다. `앙상블 균형`(1층 B구역 7열 11~14번)으로 바꾸면 강조와 상세 이유가 함께 바뀐다. 선택은 추천안 비교이며 티켓 확보가 아니다.
6. 선택적으로 `추천 기준 조정`을 열어 `전체 음향 균형 우선`을 입력하고 적용한다. 모의 응답이 `앙상블 균형`을 먼저 표시하고 반영한 Current Need를 설명한다. 입력하지 않아도 5단계에서 핵심 흐름을 완료할 수 있다.
7. 조정 취소는 적용된 결과를 유지한다. 초기화는 기본 추천으로 돌아간다. Overview로 갔다 Seat로 돌아오면 같은 세션의 선택을 유지한다. 뒤로가기로 Overview → For You → App Home을 다시 확인한다.

단축 경로: For You의 좌석 요약 선택 → 해당 공연 Seat. 직접 상세 주소 진입·새로고침은 같은 데모 사용자를 초기화하고 해당 공연·탭을 연다. 이는 데모 라우팅 검증이며 실제 인증 후 딥링크 복귀 정책의 확정이 아니다.

### 실행

저장소 루트에서 Node 24를 사용한다. 설치 버전은 [package-lock](../../package-lock.json), 명령은 [package.json](../../package.json)에 고정한다.

```sh
npm ci
npm run dev -- --port 3000
```

실제 확인 주소: `http://127.0.0.1:3000/demo`. 3절의 App Home → For You → 데모 실내악 공연 → Seat를 따른다. 포트가 사용 중이면 `--port 3001` 등 비어 있는 포트를 지정한다. 프로덕션 빌드는 `npm run build`, 실행은 `npm run start -- --port 3001`이다.

```sh
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
```

브라우저 테스트는 기본 3000번 개발 서버를 사용하거나 자동 시작한다. 캡처는 아래 15개 파일로 갱신된다. 문서 검사는 [협업 문서](../process/WORKFLOW_AND_AGENT_HANDOFF.md) 12절의 Python 가상환경 절차를 따른다.
