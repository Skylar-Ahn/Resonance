# Resonance Discussion Note

> **Date:** 2026-09-18  
> **Topic:** App Home·Splash 공명 비주얼 재정의  
> **Area:** UX/UI  
> **Status:** Partially Decided  
> **Related:** `docs/design/DESIGN_SYSTEM.md`, `docs/design/INTERACTION.md`, `docs/design/RESPONSIVE.md`, `docs/design/REFERENCE_MAP.md`, `docs/product/IA.md`, `docs/decisions/DECISION_LOG_AND_OPEN_QUESTIONS.md`

## 1. Context

App Home의 리퀴드 글라스·cymatics·노란 종이배 조합을 다시 검토했다. 기존 조합은 감각적으로는 매력적이지만, 수중 caustics처럼 읽히는 배경·수면 위 오브젝트인 종이배·독립된 물방울/원형 cymatics가 서로 다른 물리적 세계를 암시해 은유가 과밀해지는 문제가 있었다.

또한 이전의 순수 검정 배경 + 고립된 원형 cymatics 목업은 중앙 오브젝트가 물의 파동보다 “우주 속 지구/행성”으로 읽히는 문제가 확인되었다. 사용자는 이 문제를 이유로 검정 배경안을 이미 반대했으며, 이번 논의에서 App Home과 Splash의 시각 언어를 다시 정리했다.

## 2. Key Discussion

| 구분 | 핵심 내용 |
| --- | --- |
| 고민한 문제 | 물성 배경, 원형 cymatics, 노란 종이배를 함께 사용할 때 각각의 의미가 충돌하며, App Home이 과도한 은유나 행성 이미지로 읽히는 문제 |

## 3. Options Considered

### Option A — 순수 검정 배경 + 고립된 원형 cymatics

- 핵심: 검정 배경 위에 완전한 원 형태의 cymatics를 중심 오브젝트로 배치
- 장점: 높은 대비, 정보 위계와 흰 타이포그래피 강조
- 문제점: 원형 오브젝트가 물의 파동보다 우주 속 지구·행성으로 읽힘
- 결과: **폐기**

### Option B — 강한 물성 배경은 Splash에만 사용

- 핵심: caustics/수중 빛 배경을 Splash로 이동하고 Home에서는 제거
- 장점: Splash의 시적·브랜드적 역할을 강화하고 Home의 정보 구조를 단순화할 수 있음
- 문제점: Home에서 cymatics와 노란 오브젝트가 물·파동으로 읽히는 문맥까지 사라질 수 있음
- 결과: **단독 채택하지 않음**

### Option C — Splash/Home에 같은 물성을 서로 다른 강도로 사용

- 핵심: Splash에서는 물성·빛의 흔들림을 강하게 보여주고, Home에서는 같은 물성을 어둡고 절제된 형태로 유지. cymatics는 배경과 이어지는 파동 현상으로 표현
- 장점: Splash와 Home의 세계관을 연결하면서 행성 인상과 물리적 모순을 줄임
- 결과: **채택**

## 4. Decisions

### Decided

- **Splash와 App Home은 같은 물성의 세계를 공유한다.**
  - Splash에서는 caustics/수중 빛 같은 물성을 가장 강하게 보여준다.
  - App Home에서는 같은 물성을 훨씬 어둡고 절제된 상태로 유지한다.

- **App Home의 순수 검정 배경은 사용하지 않는다.**
  - 이유: 고립된 원형 cymatics와 결합할 때 우주·지구·행성 이미지로 읽히는 문제가 반복되었다.

- **cymatics는 독립된 원형 물체가 아니라 배경과 연결된 파동 현상으로 표현한다.**
  - 360도 외곽선이 강한 물방울·유리구·원판 표현을 피한다.
  - 중심에서 발생한 파동이 주변 매질로 이어지는 인상을 우선한다.

- **LP는 형태보다 행동으로 인용한다.**
  - 완전한 LP 원판을 직접 묘사하기보다, 작은 인터랙션 오브젝트의 이동과 파동 반응을 통해 stylus/LP의 기억을 간접적으로 남긴다.

- **노란색 브랜드 아이덴티티와 작은 상호작용 오브젝트의 역할은 유지한다.**
  - 오브젝트는 파동과 상호작용하거나 파동의 시작점 역할을 한다.

### Tentative

- **노란 오브젝트의 최종 형태로 ‘종이배’를 유지할지는 미확정이다.**
  - 종이배는 물 위에 띄우는 행동이 자연스럽고 stylus 대체물로 시작된 유력 후보지만, 제품 의미보다 시적 장식으로 먼저 읽힐 위험이 있다.
  - 종이배, 추상화된 접힘 형태, stylus를 암시하는 기하 오브젝트를 비교할 필요가 있다.

- **cymatics의 정확한 원형성·경계 강도·파동 밀도는 미확정이다.**
  - LP 연상이 가능한 수준과 ‘행성/원판’처럼 고립되어 보이지 않는 수준 사이의 시각 검증이 필요하다.

## 5. Open Questions

- **Q-01.** 작은 노란 상호작용 오브젝트의 최종 형태는 종이배인가, 더 추상적인 형태인가?
- **Q-02.** 기존 실제 음악 재생 UI의 Play / Pause / Resume / Stop 상태를 새 cymatics + 노란 오브젝트 구조에 어떻게 매핑할 것인가?
- **Q-03.** 재생 중 작곡가·연주자 portrait를 표시하던 기존 LP 중앙 상태는 폐기할지, 다른 방식으로 보존할지?
- **Q-04.** Splash → App Home 전환에서 물성 강도와 파동 상태를 어떤 animation으로 연결할 것인가?
- **Q-05.** App Home의 최종 어두운 palette/token과 텍스트 대비를 어떻게 정의할 것인가?
- **Q-06.** LP 연상은 사용자가 즉시 인지해야 하는 핵심 의미인가, 알아차릴 수도 있는 보조적 인용으로 남길 것인가?
